Error State Shake

Transición de sacudida horizontal multi-fase calculada con curvas cubic-bezier. Mantiene el ancho y grosor del borde idéntico (cero saltos de layout) y se auto-limpia en cuanto el usuario tipea.

Comando para Antigravity Copia y pega en el chat

Vista Previa Presiona Enter en el input

Por favor ingresa un correo válido.

export function ActionMenu() {
  const [open, setOpen] = useState(false)

  return (
    <Liquid blur={6} contrast={18} fill="#141414" shadow="0 4px 18px rgba(0,0,0,.45)">
      <Liquid.Item x={open ? -54 : 0} y={open ? -34 : 0} transition="bouncy">
        <button className="round-btn"><DownloadIcon /></button>
      </Liquid.Item>
      <Liquid.Item x={0} y={open ? -64 : 0} transition="bouncy" delay={35}>
        <button className="round-btn"><HeartIcon /></button>
      </Liquid.Item>
      <Liquid.Item x={open ? 54 : 0} y={open ? -34 : 0} transition="bouncy" delay={70}>
        <button className="round-btn"><ShareIcon /></button>
      </Liquid.Item>
      <Liquid.Item x={0} y={0}>
        <button className="round-btn main" onClick={() => setOpen(!open)}>+</button>
      </Liquid.Item>
    </Liquid>
  )
}
