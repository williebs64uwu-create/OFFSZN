4. Dónde va cada archivo: ImageKit vs Cloudflare R2

Tipo de Archivo Destino Óptimo ¿Por qué?
Portadas, Avatares, Banners, UI ImageKit Comprime automáticamente imágenes a formato WebP/AVIF ultra liviano, genera miniaturas al vuelo y tiene CDN global inmediata.
Videos MP4 (ej. omni-beat.mp4) Cloudflare R2 Cloudflare R2 tiene cero costo de transferencia saliente (Zero Egress). Transmite gigabytes de video sin cobrarte ni un centavo.
Audios MP3 / Previews de Beats Cloudflare R2 Soporta cabeceras HTTP Range (código 206) para reproducción instantánea con barra de tiempo sin sobrecargar el servidor.
Instaladores VST3/AU y ZIPs de pago Cloudflare R2 (Privado) Se descargan mediante URLs firmadas con vencimiento de 1 hora. Máxima seguridad sin consumo de Vercel.

5. Fluid Compute en Vercel (Optimización de Memoria)

En tu captura anterior se observaba: Fluid Active CPU: 35s / 4h. Esto es parte de la nueva arquitectura de Vercel.

  • En Project Settings ➔ Functions, verifica que la memoria de las funciones esté en 1024 MB (el valor predeterminado más eficiente).
  • Con el cambio que hicimos en vercel.json, las landings ahora se sirven como archivos estáticos. La CPU de Fluid apenas se usará unos segundos al día, garantizando cero costos.

6. Mapa Maestro de Variables de Entorno (.env)

Todas estas variables están configuradas en tu archivo server/.env y deben estar cargadas en Vercel (Settings ➔ Environment Variables):

SUPABASE_URL
URL de tu proyecto en Supabase (Base de datos y autenticación).
SUPABASE_SERVICE_KEY
Clave con permisos de administración para backend.
JWT_SECRET
Firma de tokens de sesión para usuarios y creadores.
AGENT_ACCESS_KEY
Clave maestra para endpoints internos y automatizaciones.
MERCADOPAGO_ACCESS_TOKEN
Token de producción de MercadoPago para cobros en PEN/USD.
PAYPAL_CLIENT_ID / SECRET
Credenciales de la API de PayPal para checkout internacional.
R2_ENDPOINT_V4 / V3 / V2
Endpoints S3 de tus buckets en Cloudflare R2.
R2_ACCESS_KEY / SECRET
Credenciales de acceso a Cloudflare R2 con permisos de lectura/escritura.
IMAGEKIT_PUBLIC / PRIVATE
Credenciales para compresión y entrega rápida de imágenes.
PLUGIN_PRIVATE_KEY
Clave RSA/ECDSA para firmar licencias de Easy Mix, Omni y Star Chain.

7. Protocolo de Despliegues Seguros (Checklist Rápido)

📋
Antes de hacer cualquier deploy en el futuro:
  1. Ejecuta siempre node --check server/src/app.js para evitar errores de sintaxis.
  2. No agregues carpetas pesadas (videos, wavs, zips) dentro del repositorio Git; súbelas directamente a Cloudflare R2.
  3. Mantén las listas includeFiles y excludeFiles de vercel.json por debajo de 256 caracteres cada una para evitar errores de build en Vercel.
  4. Si alguna vez lanzas una landing nueva, agrégala en vercel.json apuntando a su .html estático.
