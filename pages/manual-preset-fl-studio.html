Cómo instalar tus plugins

Instala en este orden y con FL Studio cerrado. Cada bloque tiene los pasos y, dentro, los botones de descarga.

1FL Studio 26

  1. Instalar el archivo descargado de Fl studio v26 es un archivo .exe ejecutable para windows
    Descargar para Windows ↗ Descargar para Mac ↗
  2. Ya estará activado listo para usar (NO se necesita activaciones, ya viene activado el instalador)
PARA MAC: (SEGUIR MISMOS PASOS, PRIMERO DESCOMPRIMIR EL .RAR CON WIN RAR)

2Waves · versión V16

  1. Crearte una cuenta en waves.com
    Ir a waves.com ↗
  2. Descargar Waves Central
    Descargar Waves Central ↗
  3. Cerrar FL Studio
  4. Abrir Waves Central
  5. Iniciar session o Crear tu cuenta del Waves Central
  6. Ir a “Install Products”
  7. Clickear en All Products
  8. En View seleccionar solo V16 Version (¡y nada más!)
  9. Seleccionar todos los plugins que necesitas en V16, si no sale algun plugin tener en consideración lo siguiente:
    • Deeser = puedes buscarlo como “dee” o “de”
    • RVOX = puedes buscarlo como “Renaissance Vox” o “Renaissance”
    • SSL EQ = puedes buscarlo como “SSL” e instalas todos los que salen.

    Plugins de Waves que necesitas:

    • NS1
    • DeEsser
    • API-560
    • C6 Multiband Compressor
    • SSL EQ
    • Renaissance Vox (RVox)
    • CLA Vocals
    • CLA-76
    • PuigTec EQs (EQP1A)
    • L4 Ultramaximizer
    • H-Delay
    • Doubler
    • S1 Imager
    • Abbey Road Chambers
    • Abbey Road J37 Tape
  10. Click en “Install” se encontrará en la parte derecha
  11. Despues de que termine de instalar todo, cerrar el waves central, NO ABRIR EL FL STUDIO O TU DAW AÚN
  12. Descargar este archivo para poder activar los plugins
    Descargar activador de Waves ↗
  13. Darle doble click al archivo que descargaste de mediafire que se llama: Waves_Ultimate_2025.3_patch.exe
  14. Reiniciar la PC
  15. Abrir el Fl studio o tu daw, escanea completamente los plugins con todas las opciones.
  16. Ya estarán instalados y activados!

3FabFilter

  1. CIERRA FL STUDIO
  2. INSTALAR PLUGINS QUE NECESITAS:
    Pro-Q 4 ↗ Pro-MB ↗ Pro-DS ↗
  3. USAR ESTE ACTIVADOR PARA TODOS LOS PLUGINS DE FAB FILTER:
    Descargar activador ↗
    Si bloquea al abrir: (dar click a "más información > ejecutar de todas maneras"
  4. DARLE A “REGISTER" luego a "GENERATE" > luego puedes cerrar esa ventana.
Si instalas uno nuevo, repetir proceso de “register y generate”

4Ozone 12

  1. CIERRA FL STUDIO
  2. Descargar el instalador
    Descargar para Windows ↗ Descargar para Mac ↗
  3. Dale doble click para abrir el instalador
    Si bloquea al abrir: (dar click a "más información > ejecutar de todas maneras"
  4. Darle todo a “SIGUIENTE” o “NEXT”
  5. luego de eso, el plugin estará instalado.
NO SE NECESITA NINGUNA ACTIVACIÓN EXTRA.
