## Qué medir mínimo

Instagram
- Views, Likes, Comments, Saves, Shares, Followers gained

TikTok
- Views, Likes, Comments, Saves, Shares (opcional), Followers gained

## Rates clave (targets)

- Save Rate sugerido (motor de alcance): ~3.5%
- Comment Rate (motor de conversación/DM): ~2.5%

Fórmulas (por plataforma)
- Save Rate = saves / views
- Comment Rate = comments / views

## Benchmarks (referencias)

De tu base:
- “Antes/Después”: ratios altos de guardados/comentarios cuando hay A/B real + CTA específico.
- “Cheat code / pack”: levanta comments/saves cuando el valor es “colección” y el CTA es palabra única.
- Carrusel: “listas accionables” genera guardados; “reflexivo” no.

## Reglas de decisión (operación)

- Repetir (repost/variación) cuando:
  - Save Rate >= 3.5% o Comment Rate >= 2.5%
  - o cuando el post genera DMs/ventas aun con views moderadas
- Iterar (mismo hook, nuevo ángulo) cuando:
  - Views altos pero rates bajos (se consumió, no se guardó)
- Matar (no insistir) cuando:
  - Views bajos + rates bajos, y no hay señal de DM/ventas
