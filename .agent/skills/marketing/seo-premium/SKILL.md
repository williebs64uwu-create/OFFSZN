# SEO & AI Visibility
## Cuándo usar este skill
- Al crear nuevas páginas que deban ser indexables.
- Cuando el usuario quiera mejorar el ránking de sus términos clave.
- Para asegurar que la IA (Search Generative Experience) cite correctamente el proyecto.

## Inputs necesarios
- **Página**: HTML o meta-datos actuales.
- **Palabras Clave**: Qué términos queremos dominar.
- **Contexto**: `.agent/recursos/marketing-context.md`.

## Workflow
1) **Análisis On-Page**: Revisión de H1, títulos, meta-descriptions y alt texts en imágenes.
2) **Estructura Técnica**: Validar Sitemap, Robots.txt y velocidad de carga (Core Web Vitals).
3) **Arquitectura de Site**: Revisar jerarquía de URLs y enlaces internos.
4) **Optimización para AI (AEO/LLMO)**: Estructurar datos con JSON-LD para que los modelos de lenguaje extraigan la información correctamente.
5) **Generación de Contenido**: Crear listas de temas basados en "intentos de búsqueda".

## Instrucciones
- No rellenes palabras clave (keyword stuffing). Escribe para humanos, optimiza para bots.
- Prioriza el cargado rápido: el SEO moderno es UX.
- Usa Schema Markup (JSON-LD) en todas las páginas críticas (Productos, FAQs, Perfiles).
- **Checklist**:
  - [ ] Tag H1 único por página.
  - [ ] Meta-tags descriptivos y breves.
  - [ ] Imágenes comprimidas con alt descriptivo.
  - [ ] Datos estructurados válidos.

## Manejo de errores y correcciones
Si el usuario pide "trucos" de SEO que puedan penalizar la web (black hat), adviértele sobre las consecuencias a largo plazo y propón una alternativa ética de "white hat".
