# Copywriting Premium
## Cuándo usar este skill
- Cuando el usuario necesite redactar titulares impactantes (Hero sections).
- Cuando el copy actual sea "débil" o puramente descriptivo/técnico.
- Cuando se necesiten CTAs accionables que no sean genéricos (evitar "Suscribirse").
- Para descripciones de producto que vendan beneficios, no solo características.

## Inputs necesarios
- **Contexto**: `.agent/recursos/marketing-context.md` (Obligatorio leerlo primero).
- **Objetivo**: Qué acción única debe tomar el usuario en esta sección/página.
- **Audiencia**: A quién le estamos hablando en este momento específico.

## Workflow
1) **Análisis de Contexto**: Leer el archivo de marketing context para alinear el tono y la propuesta de valor.
2) **Definición de Ángulo**: Elegir un framework (PAS: Problema-Agitación-Solución, AIDA o Beneficios Directos).
3) **Borrador de Titular**: Generar 3 opciones variando el enfoque (Resultado, Curiosidad, Miedo a perderse algo).
4) **Cuerpo y Beneficios**: Transformar características técnicas en resultados emocionales para el usuario.
5) **CTA de Alto Valor**: Diseñar botones que describan el valor que el usuario recibe al hacer click.

## Instrucciones
- Prioriza claridad sobre creatividad. Si no se entiende en 3 segundos, fallaste.
- Usa lenguaje del cliente (extraído del contexto), evita jerga corporativa.
- **Formulas de Titulares**:
  - "{Resultado deseado} sin {punto de dolor}"
  - "El {categoría} para {tipo de usuario}"
  - "Deja de {problema} hoy mismo"
- **CTAs**: Usa [Acción] + [Valor]. Ej: "Empieza a cobrar hoy" > "Regístrate".

## Output (formato exacto)
### 🖋️ Propuesta de Copy
**Titular**: [Opción Ganadora]
**Sub-titular**: [Explicación concisa]
**CTA Principal**: [Texto del botón]

---
**Opciones Alternativas**:
- Opción B (Enfoque en [X])
- Opción C (Enfoque en [Y])

**Racional**: [Breve explicación de por qué este copy convertirá mejor]

## Manejo de errores y correcciones
Si el tono se siente muy agresivo o "vendedor de humo", suaviza los adjetivos y aumenta los datos específicos/beneficios tangibles. Si el usuario pide algo "creativo" que sacrifica la claridad, adviértele primero.
