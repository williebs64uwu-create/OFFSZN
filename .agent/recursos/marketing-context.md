# Contexto Maestro de Marketing - OFFSZN

Este documento es la base para todos los skills de marketing relacionados con el proyecto. Los agentes deben leer este archivo ANTES de generar copy, analizar CRO o proponer estrategias de crecimiento.

## 1. Producto / Oferta
- **Nombre**: OFFSZN
- **Categoría**: Marketplace / Plataforma de servicios para productores musicales y creadores.
- **Propuesta Única de Valor (USP)**: La plataforma con la estética más premium y la experiencia más rápida para que productores vendan sus servicios y beats.
- **Transformación**: De ser un productor "desconocido" en redes sociales a tener un perfil profesional con checkout directo y gestión de pedidos automatizada.

## 2. Audiencia Ideal (ICP)
- **Perfil 1: El Productor**: Busca profesionalismo, facilidad para cobrar y una marca personal sólida.
- **Perfil 2: El Artista/Creador**: Busca beats de calidad, servicios rápidos (mezcla, mastering) y una interfaz confiable.
- **Problemas**: Falta de confianza al pagar por internet, procesos manuales lentos, diseños mediocres en otras plataformas.

## 3. Objeciones Comunes
- **Precio**: "¿Por qué pagar comisión aquí si puedo usar PayPal directo?" (Respuesta: Protección al comprador, portafolio premium, flujo de trabajo).
- **Confianza**: "¿Le llegará el dinero al productor? ¿Me llegará el beat?".
- **Facilidad**: "¿Es muy difícil subir mis productos?".

## 4. Voz de Marca (Borrador)
- **Tono**: Profesional, Minimalista, Inspirador, Directo.
- **Estética Visual**: Deep Dark, Glassmorphism, Tipografía moderna (Outfit/Inter).
