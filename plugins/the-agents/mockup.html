Una skill es una receta tuya

Tus presets que ya funcionan se vuelven skills: dicen cuándo aplicarlos y qué mover. Así la IA no inventa y tu forma de mezclar es lo que se vende.

{
  "skill": "voz-trap-limpia",
  "agente": "clover",
  "cuando": { "fuente": "voz", "sibilancia": "> 6 dB", "ruido": "> -60 dB" },
  "cadena": [
    { "plugin": "clover.deesser", "banda": "5.8 kHz", "reduccion": "-4 dB" },
    { "plugin": "clover.limpieza", "ruido": "-12 dB" }
  ],
  "origen": "Vocal Preset > Trap"
}
