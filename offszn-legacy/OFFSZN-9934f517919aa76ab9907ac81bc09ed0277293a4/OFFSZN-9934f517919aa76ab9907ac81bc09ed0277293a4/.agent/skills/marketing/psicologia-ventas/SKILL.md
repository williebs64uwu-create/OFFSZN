# Psicología de Ventas en UI
## Cuándo usar este skill
- Al diseñar modales, banners de precios o tarjetas de productos.
- Cuando la interfaz se sienta "estática" o sin urgencia.
- Para mejorar la confianza en el proceso de checkout.

## Inputs necesarios
- **Componente**: UI a mejorar.
- **Contexto**: `.agent/recursos/marketing-context.md`.

## Workflow
1) **Identificación de Triggers**: Elegir qué sesgos cognitivos aplicar (Prueba Social, Escasez, Reciprocidad, Anclaje de Precios).
2) **Implementación Visual**: Diseñar el elemento (ej: badge de "Más popular", contador de tiempo, lista de "Quién está comprando").
3) **Refinamiento Ético**: Asegurar que la urgencia sea real y no patrones oscuros (Dark Patterns).

## Instrucciones
- **Prueba Social**: Muestra que otros están usando el servicio. "12 artistas compraron esto hoy".
- **Anclaje**: Pon el plan más caro al lado del recomendado para que este se sienta barato.
- **Escasez**: "Solo quedan 2 slots para beats exclusivos".
- **Autoridad**: Usa logos de marcas o menciones de artistas famosos si los hay.

## Output (formato exacto)
### 🧠 Mejora Psicológica de UI
**Trigger Utilizado**: [Nombre del sesgo]

#### 🎨 Cambio en Diseño
- [Descripción del cambio en el elemento]

#### 💡 Justificación
- "Aplicamos [X] porque el cerebro humano tiende a [Y] cuando ve [Z]."

## Manejo de errores y correcciones
Evita el uso excesivo de popups de "Urgencia". Si hay demasiados, el usuario siente ansiedad y abandona. Menos es más.
